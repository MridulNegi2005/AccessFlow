# Local ASR verification, 15 September 2026

Faster Whisper now runs on the Workstream A machine. This records what the committed audio
fixtures actually transcribe to, because an earlier measurement used the wrong fixture and
its result was read as an ASR problem.

## Setup

`faster-whisper` was not installed on this machine. It is an optional extra in
`pyproject.toml`. Install it with the project's own lockfile:

```
uv sync --extra audio --extra dev
```

Resolved `faster-whisper==1.2.1`, the same version Atishay recorded. Model `base.en`, CPU,
`int8`. First load downloads the snapshot and took 14.83 seconds; later loads read the cache.

Hugging Face warns that this machine cannot use cache symlinks, so the cache uses more disk.
That is a storage note, not a failure.

## Measurements

| Fixture | Duration | Inference | Realtime factor | Transcript |
|---|---|---|---|---|
| `synthetic_speech.wav` | 5.30 s | 1.21 s | 0.23 | `My screen keeps flickering after the update.  Book Wednesday at 5.` |
| `synthetic_pause_correction.wav` | 6.02 s | 1.18 s | 0.20 | `Book Tuesday  Actually, Wednesday at 5` |
| `synthetic_tone.wav` | 0.50 s | 1.05 s | 2.09 | empty |

## Correcting the earlier reading

`docs/feedback/ASR_MEASUREMENTS.md` records a 13 September run with an empty transcript. That
run used `synthetic_tone.wav`, which contains a tone and no speech, so an empty transcript is
the correct output for it. It is not evidence that ASR fails.

The two speech fixtures transcribe correctly. `synthetic_pause_correction.wav` contains a
correction after a pause, which is the interruption case the project exists to handle.

Realtime factor is below 0.25 for both speech fixtures, so ASR is not the latency risk on
this hardware. The tone fixture's factor of 2.09 is model load and fixed overhead measured
against half a second of audio, not a throughput result.

## Limits

This is adapter-level evidence on one machine. It is not an end-to-end controller run, and it
is not a speech-quality measurement against a labelled reference. Both fixtures are
synthetic, and their provenance is recorded in `docs/feedback/PROVENANCE.md`.

No word error rate is claimed. Judging these transcripts by eye against the intended text is
not a measurement.
